# Master Deployment Fix & Codebase Cleanup Implementation Plan

## Overview
This plan addresses logic fragmentation in the AI layer, completes missing tool scaffolds, and enhances the Maintenance Configurator to handle dynamic property data. It also finalizes the transition to OpenRouter and resolves Sentry configuration warnings.

## Scope Definition (CRITICAL)
### In Scope
- Refactor `src/app/api/agreements/recommend/route.ts` to use centralized `openrouter` provider.
- Implement `src/app/tools/outdoor-living/page.tsx` and `src/app/tools/home-theater/page.tsx` as scaffolds.
- Update `MaintenanceConfigurator.tsx` to fetch property data via hash from database.
- Resolve Sentry v10 deprecation warnings in `next.config.ts`.
- Fix `maxSteps` type error in `src/app/api/chat/route.ts` by updating provider usage or adding proper overrides.

### Out of Scope (DO NOT TOUCH)
- Re-designing the UI of existing tools.
- Changing the database schema.
- Implementing the actual logic for Outdoor Living / Home Theater (Sprint 3 tasks).
