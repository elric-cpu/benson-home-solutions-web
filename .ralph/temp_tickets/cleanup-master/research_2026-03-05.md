# Research: Master Deployment Fix & Codebase Cleanup

**Date**: 2026-03-05

## 1. Executive Summary
The Benson Home Solutions codebase contains several functional tools and routes but suffers from logic fragmentation in AI provider usage and incomplete feature implementations. While the core geocoding and property enrichment pipeline is operational, the recommendation engine and configurator tools lack centralized logic and dynamic data handling.

## 2. Technical Context
- **AI Recommendation Engine**: `src/app/api/agreements/recommend/route.ts:61-70` uses a fragmented logic to select between Anthropic and OpenAI providers based on environment variables, rather than utilizing the centralized OpenRouter provider in `src/lib/ai/provider.ts`.
- **Maintenance Configurator**: `src/app/tools/maintenance-configurator/MaintenanceConfigurator.tsx:40` uses a hardcoded `property` object for demo purposes, preventing dynamic configuration based on user-entered address data.
- **Tools Scaffold**: `src/app/tools/cost-estimator/page.tsx` contains a static scaffold message ("AI estimator coming Sprint 3").
- **Missing Features**: Routes for `outdoor-living` and `home-theater` tools mentioned in the conversion architecture are missing from `src/app/tools/`.
- **Dependencies**: Current `package.json` includes `ai: 6.0.115`, `@ai-sdk/openai: 3.0.40`, and `@sentry/nextjs: 10.42.0`. Node.js is set to `22` in `.nvmrc`.

## 3. Findings & Analysis
- **AI Provider Inconsistency**: The project is transitioning to OpenRouter but `recommend/route.ts` still imports `@ai-sdk/anthropic` and `@ai-sdk/openai` directly.
- **Data Flow Gaps**: There is no established mechanism to pass property data from the `TrueCostCalculator.tsx` results to the `MaintenanceConfigurator.tsx` beyond the initial lead capture.
- **Build State**: Local build succeeds, but Sentry v10 deprecation warnings are present in the build logs if `disableLogger` or `automaticVercelMonitors` are used in `next.config.ts`.

## 4. Technical Constraints
- **Vercel AI SDK**: Using version 6.x (beta/latest), which introduced `maxSteps` and other multi-step features.
- **Sanity CMS**: `src/lib/ai/config.ts` depends on Sanity for the chatbot system prompt, with a local fallback.

## 5. Architecture Documentation
- **Centralized AI**: `src/lib/ai/provider.ts` exports the `openrouter` instance.
- **Database Schema**: `src/lib/db/schema.ts` defines all critical tables including `properties`, `agreements`, and `audit_log`.
