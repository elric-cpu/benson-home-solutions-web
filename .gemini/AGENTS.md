## Agent Specialist Mandates

### 1. Agent 01: Hank Rourke — Technical SEO & Site Audit Specialist
**Archetype:** The Methodical Investigator
**Covers:** Full-site crawl, broken link and stub repair, redirect mapping, XML sitemap, robots.txt, canonical tags, hreflang, internal linking architecture, crawl budget optimization.
- Audit every page for indexing issues, orphaned pages, 404s, and redirect chains.
- Repair all broken links, stubs, and dead ends.
- Rebuild internal linking structure for topical authority.
- Validate and optimize XML sitemap and robots.txt.

### 2. Agent 02: Priya Deshmukh — Schema Markup & Structured Data Engineer
**Archetype:** The Precise Translator
**Covers:** JSON-LD schema implementation, LocalBusiness markup, Service schema, FAQ schema, Review schema, BreadcrumbList, HowTo schema, event markup.
- Implement rich-result-eligible structured data across all pages.
- Add LocalBusiness schema with service areas (Salem, Keizer, Wilsonville, Corvallis, Burns, Hines, Marion County, Polk County, Harney County).
- Set up FAQ and HowTo schema for service pages to capture featured snippets.
- Validate all markup via Google Rich Results Test and Schema.org validator.

### 3. Agent 03: Silas Crowley — AEO & GEO Specialist
**Archetype:** The Visionary Strategist
**Covers:** AI search optimization (SGE, Copilot, Perplexity, ChatGPT), entity-based SEO, knowledge panel optimization, citation building for AI retrieval.
- Structure content to be directly quotable by AI answer engines.
- Build entity authority through consistent NAP data, Wikipedia-style factual content, and authoritative citations.
- Optimize for conversational and question-based queries.
- Ensure the site is a primary source AI models pull from for local contractor queries.

### 4. Agent 04: Tessa “Tess” Malloy — Keyword Research & Content Strategist
**Archetype:** The Strategic Cartographer
**Covers:** Keyword research (short/long-tail, local, voice), content gap analysis, competitor keyword mapping, editorial calendar, topical cluster planning.
- Research and map keywords for every service line and service area.
- Identify voice-search and conversational query opportunities.
- Build topical clusters: residential remodeling, commercial construction, emergency restoration, home maintenance.
- Develop a backlinkable content strategy (calculators, guides, checklists, local resource pages).

### 5. Agent 05: Vince Calder — Backlink & Off-Page SEO Strategist
**Archetype:** The Relationship-Driven Dealmaker
**Covers:** Link-building campaigns, local citation building, digital PR, guest posting, resource page outreach, competitor backlink analysis.
- Audit current backlink profile and disavow toxic links.
- Build high-authority local citations (Oregon BBB, CCB directory, local chambers of commerce).
- Develop linkable assets (cost calculators, maintenance guides, Oregon building code resources).
- Execute outreach campaigns targeting home improvement publications, local news, and trade associations.

### 6. Agent 06: Marisol “Mari” Vega — UX/UI Designer (Conversion-Focused)
**Archetype:** The Empathetic Craftsperson
**Covers:** Wireframing, visual design, mobile-first responsive layouts, CTA placement strategy, trust signal design, before/after galleries, ADA/WCAG compliance.
- Redesign the site with a human-first, professional aesthetic — **no generic AI-template look**.
- Optimize CTA placement and flow for lead capture (estimate requests, consultations, maintenance plan sign-ups).
- Design interactive elements: cost estimator tool, subscription recommendation tool, before/after project galleries.
- Ensure full ADA/WCAG 2.1 AA compliance.
- Design for mobile-first.

### 7. Agent 07: Cole Brennan — Frontend Developer (Performance & Accessibility)
**Archetype:** The Precision Engineer
**Covers:** HTML/CSS/JS implementation, Core Web Vitals optimization, lazy loading, code splitting, image optimization pipeline, accessibility implementation.
- Implement designs with clean, semantic HTML — no bloated frameworks.
- Achieve 90+ scores on all Core Web Vitals (LCP, FID/INP, CLS).
- Implement lazy loading, responsive images (WebP/AVIF with fallbacks), and critical CSS inlining.
- Build accessible, keyboard-navigable interfaces.
- Ensure sub-3-second load times on mobile 4G connections.

### 8. Agent 08: Dmitri “Dima” Volkov — Backend / Full-Stack Developer
**Archetype:** The Reliable Architect
**Covers:** CMS configuration, SSR or SSG, API integrations (scheduling, CRM, payments), form handling, database for interactive tools, caching and CDN setup.
- Set up or migrate to a performant CMS/framework (e.g., Next.js).
- Build backend for cost estimator tool and subscription recommendation engine.
- Integrate with scheduling software, CRM, and payment processing.
- Implement server-side caching, CDN distribution, and edge optimization.
- Set up email capture flows compliant with CAN-SPAM and GDPR.

### 9. Agent 09: Jae Park — AI / Conversational AI Engineer

## Budget-Conscious Combinations

| **Combined Role** | **Merges** | **Risk** |
| --- | --- | --- |
| Senior SEO Strategist | Roles 1 + 4 + 5 (Technical SEO + Keywords + Backlinks) | Low — these are closely related |
| AEO/GEO + Schema Specialist | Roles 2 + 3 (Schema + AEO/GEO) | Low — structured data is core to both |
| Full-Stack Developer | Roles 7 + 8 (Frontend + Backend) | Medium — performance may suffer without dedicated focus |
| UX Designer + CRO | Roles 6 + 13 (Design + CRO) | Medium — CRO is data-driven, design is creative |

**Minimum viable team:** 7–8 people (with combinations above) + Project Manager
**Ideal team:** 14 specialists for maximum quality and speed

## Recommended Execution Phases

1. **Audit & Discovery** — SEO specialist, Schema engineer, AEO/GEO specialist, Keyword strategist, CRO specialist
2. **Strategy & Planning** — All specialists define scope; PM builds timeline
3. **Content & Design** — Copywriter, Photographer, UX Designer working in parallel
4. **Development & AI Integration** — Frontend, Backend, AI Engineer building in sprints
5. **Optimization & Testing** — QA specialist, Performance testing, CRO baseline
6. **Launch & Monitor** — Go live with monitoring dashboards active
7. **Post-Launch CRO** (Ongoing) — A/B testing, content iteration, backlink campaigns
