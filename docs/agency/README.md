# Agency Runtime

This directory holds the human-readable operating artifacts for Iron Ledger Digital.

- `executive-board/` contains concise leadership-facing remediation boards.
- `war-room/` contains execution-grade operational plans.
- `audits/` contains read-only audit outputs.
- `remediation-plans/` contains approved implementation packages.
- `postmortems/` contains rollback and incident review documents.
