# KPI Scorecards (Weekly)

## Shared Weekly Cadence
- **Owner:** 14
- **Format:** Monday plan, Friday scorecard
- **Traffic light:** Green (on target), Yellow (watch), Red (intervention)

## Role KPIs

### 01 Technical SEO
- Index coverage (% target pages indexed)
- Crawl errors (critical count)
- Redirect chain count

### 02 Schema
- Valid JSON-LD coverage (% eligible pages)
- Rich result eligibility count
- Validator pass rate

### 03 AEO/GEO
- AI answer inclusion rate (tracked prompt set)
- Entity consistency score
- Citation quality count

### 04 Keywords/Strategy
- Cluster coverage (% planned clusters published)
- Priority query ranking movement
- Content gap closure velocity

### 05 Backlinks/Off-page
- Referring domain quality score
- Toxic link exposure count (must trend down)
- Outreach conversion rate

### 06 UX/UI
- Form completion rate
- Mobile task success rate
- Design defect escape rate

### 07 Frontend Perf/A11y
- CWV pass rate (LCP/INP/CLS)
- Accessibility regression count
- Bundle size trend

### 08 Backend/Full-stack
- API error rate
- P95 latency (critical endpoints)
- Integration reliability (CRM/scheduling/payment)

### 09 AI Engineer
- Chat containment rate
- AI answer usefulness score
- Hallucination incident count

### 10 Copywriter
- CTR lift on rewritten pages
- Conversion assist rate by page
- E-E-A-T editorial checklist pass

### 11 Visuals
- Authentic visual coverage (% pages with real assets)
- Image performance budget pass rate
- Alt text completeness rate

### 12 QA/Testing
- Regression pass rate
- Escaped defect count
- Time-to-detect critical failures

### 13 Analytics/CRO
- Tracking completeness
- Lead-to-consultation conversion rate
- A/B test throughput and win rate

### 14 PM/Tech Lead
- Milestone predictability (% on-time)
- Risk burn-down trend
- Cross-team blocker resolution time
