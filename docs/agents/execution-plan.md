# Execution Plan (Agent Operating Model)

## Phase 1 — Audit & Discovery
**Owners:** 01, 02, 03, 04, 13  
**Inputs:** Existing site, analytics baseline, backlink profile, service-area strategy  
**Outputs:** Technical audit, schema gap list, AEO/GEO baseline, keyword map, conversion baseline

**Quality gates**
- Critical crawl/indexing defects triaged
- Current funnel and attribution baseline captured
- No unvalidated assumptions enter phase 2

## Phase 2 — Strategy & Planning
**Owners:** 14 (lead), all specialists contribute  
**Outputs:** Dependency map, sprint plan, risk log, acceptance criteria per stream

**Key dependencies**
- 10/11 final assets must be timed before final schema pass by 02
- 06 design handoff must precede 07 implementation
- 08/09 integration plans must define observability before build

## Phase 3 — Content & Design
**Owners:** 10, 11, 06 (parallel), reviewed by 14  
**Outputs:** Contractor-voice page copy, visual library, UX flows, trust-signal system

**Quality gates**
- Copy reads human-expert, not generic AI
- Image library is authentic and optimized
- CTA paths are testable and measurable

## Phase 4 — Development & AI Integration
**Owners:** 07, 08, 09  
**Outputs:** Production implementation, integrated APIs/tools, AI search/chat capabilities

**Quality gates**
- Core Web Vitals target >= 90 where feasible
- Accessibility/keyboard standards pass QA baseline
- Tool outputs deterministic and logged

## Phase 5 — Optimization & Testing
**Owners:** 12 (lead), 07/08 support, 13 measurement  
**Outputs:** Regression pack, performance report, launch checklist

**Quality gates**
- Cross-browser/mobile pass
- Lighthouse/PageSpeed/WebPageTest benchmarks documented
- Blocking defects resolved or waived by 14 only

## Phase 6 — Launch & Monitor
**Owners:** 14, 13, 12  
**Outputs:** Controlled launch, dashboard monitoring, incident playbook

**Quality gates**
- Conversion tracking and call attribution verified in production
- Error/performance alerting active
- Rollback protocol tested

## Phase 7 — Post-Launch CRO (Ongoing)
**Owners:** 13 (lead), 06/10/04 support, 14 governance  
**Outputs:** A/B test backlog, monthly optimization releases, revenue/lead lift reporting
