# Benson Home Solutions: Project Onboarding (Human-Readable)

Welcome to the Benson Home Solutions digital platform! This document will help you get started as a contributor or administrator.

## 1. Project Overview
Benson Home Solutions is a general contracting firm in Oregon (CCB #258533) that specializes in maintenance-first property protection. This website is our primary lead generation tool and client communication hub.

## 2. Getting Started
*   **For Content Managers**: Contact Elric Benson for access to **Sanity Studio**. This is where you will update text, upload photos, and manage our resource directory.
*   **For Technical Teams**:
    1.  Clone the repository from GitHub.
    2.  Install dependencies using `npm install`.
    3.  Configure your `.env` file with the necessary API keys for Sanity, Supabase, and HubSpot.
    4.  Run the development server using `npm run dev`.

## 3. Core Working Principles
*   **Accuracy Above All**: We are authoritative. Every claim we make must be backed by data and our 6-resource-per-page standard.
*   **Quality & Trust**: We use real customer questions (FAQs) and verified testimonials to build local trust.
*   **Cinematic Presentation**: Every page should look professional, utilizing our Oxblood and Cream branding and cinematic hero videos.
